Componentory modifies resource imports, the combined manifest, selected public-API
compatibility helpers, SDK guards, static color fallbacks, and release labels.
Original and imported file hashes and adaptations are in eastereggs/provenance.json.
Images, nine-patches, and XML resource bytes are retained without visual changes.
